# Data

Dataset se automatski preuzima u notebook-u.

Korišćen je Credit Card Fraud Detection dataset.

Notebook preuzima ZIP fajl, raspakuje ga i učitava CSV automatski. Zbog veličine dataseta, `creditcard.csv` nije dodat direktno u repozitorijum.

Ako je potrebno ručno pokretanje, dataset se može preuzeti sa Kaggle stranice za Credit Card Fraud Detection dataset.
